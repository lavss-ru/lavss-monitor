# SECURITY — lavss monitor

## 1. Концепция безопасности

`lavss monitor` проектируется как внутренний веб-пульт управления личной инфраструктурой. Безопасность основывается на принципе минимизации поверхности атаки (Attack Surface Reduction) и изоляции каналов передачи данных.

---

## 2. Сбор метрик и сетевая изоляция

1. **Node Exporter:**
   * Node Exporter на удалённых VPS **не должен** выставлять порты напрямую в публичный Интернет.
   * Связь между Prometheus/lavss monitor и удалёнными серверами осуществляется исключительно через защищённый туннель **WireGuard**.
2. **Публичный доступ (`monitor.lavss.ru`):**
   * Внешний доступ проксируется через Reverse Proxy с обязательным TLS/HTTPS.
   * Приложение разворачивается внутри изолированной VM/LXC в среде PVE Home.

---

## 3. Управление секретами (Secrets Management)

* Никакие пароли, токены API (Proxmox API tokens, Telegram Bot tokens), ключи базы данных или секреты не хранятся в контроле версий (Git).
* Все чувствительные данные передаются через переменные окружения (`.env` / Docker secrets).

---

## 4. Аутентификация

* В Alpha 0.1 доступ разрешён исключительно единственному пользователю — владельцу системы.
* Реализуется сессионная защита с защищёнными cookies (HttpOnly, SameSite, Secure).
* Регистрация новых пользователей заблокирована на уровне кода.
