# VISION — lavss monitor

## 1. Цель и Назначение

`lavss monitor` — единый веб-пульт наблюдения и оперативного контроля за IT-инфраструктурой владельца.

Целевой адрес: **`https://monitor.lavss.ru`**

Принцип работы системы с точки зрения пользователя:
> Пользователь открывает dashboard и за несколько секунд понимает состояние всей инфраструктуры: всё ли работает, где проблема и что требует внимания.

---

## 2. Ключевая философия продукта

Большинство существующих систем мониторинга вываливают на пользователя сотни графиков, таблиц и алертов без приоритезации.

`lavss monitor` работает иначе. Система скрывает шум и подсвечивает главное:
1. **Общий статус здоровья:** Чёткий сигнал (🟢 Все системы работают / 🟡 Требуют внимания / 🔴 Проблема).
2. **Проблемные узлы:** Выделение конкретных объектов, превысивших пороги или потерявших доступность (например, `site.ru недоступен`, `VPS-03 — диск 87%`).
3. **Лента последних событий:** Важные факты из жизни инфраструктуры (восстановление работы, завершение бэкапов, истечение SSL).
4. **Быстрый доступ к деталям:** Глубокая аналитика и подробные графики отображаются только при клике на конкретный объект.

---

## 3. Границы системы

* **Это НЕ замена Proxmox GUI, Grafana, Zabbix или Heartbeat.**
* Это **самостоятельный веб-интерфейс верхнего уровня**, собирающий агрегированные статусы из целевых источников (Node Exporter/Prometheus, Proxmox API, HTTP checks) и дающий мгновенную прозрачность.

---

## 4. Мобильная адаптивность с первого дня

Система создаётся как единый responsive web-приложение для Desktop, Tablet и Mobile.
* На смартфонах карточки перестраиваются в компактный вертикальный поток.
* Важная информация (статус, проблемы, события) доступна без скролла и сложного маневрирования по меню.
